About the project

LeafLens AI

A final-year B.Tech project exploring how deep learning, classical image processing and explainable AI can work together on a practical crop-health problem — with an interface that never shows a number the backend didn't produce.

Goals

Why this project exists

Crop diseases can devastate yield, and diagnoses often depend on expert availability. This project investigates whether CNN-based detection, visible-severity estimation and gradient-based explanations can be delivered through a single, honest research interface — where every figure is traceable to the connected backend.

The guiding rule of both the code and the UI: if the backend cannot produce a result, the interface says so — it never invents one.

Demonstration guide

What to try during the viva

  1. Home — live system status strip reads /api/status.
  2. Disease Detection — upload a leaf, pick a model, watch the real loading steps.
  3. Severity — image-processing estimate with banded categories and disclaimers.
  4. Explainable AI — Grad-CAM heatmap + overlay with opacity slider and download.
  5. Model Comparison — metrics table, charts and confusion matrices from registered evaluation files.
  6. Research — dataset statistics streamed from data/dataset_info.json.
