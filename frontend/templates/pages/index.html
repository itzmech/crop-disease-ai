Project Objectives

What this project sets out to do

Disease Detection

Identify diseases from crop-leaf images using deep learning, with calibrated confidence and top-k alternatives.

Severity Assessment

Estimate the visibly affected portion of the leaf using image processing — Otsu segmentation within a leaf mask.

Explainable AI

Use Grad-CAM to visualize the image regions influencing the model prediction — no black-box outputs.

Model Research

Compare Custom CNN, ResNet50, MobileNetV2 and EfficientNetB0 using measured experimental results only.
